### Instructions

- firstly, you have the build the project, in the root directory type :
```
make
```
- now you have the executable. simply run it with the corresponding commands.
```
./codexion <coders> <burnout> <time_compile> <time_debug> <time_refactor> <req_compiles> <scheduling>

# coders : how many coders in the simulation
# burnout : time until a coder burns out
# time_compile : time it takes to compile
# time_debug : time it takes to debug
# time_refactor : time it takes to refactor
# req_compiles : how many compilations for each coder
# scheduling : scheduling method ( either fifo or edf)
```
