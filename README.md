### Instructions

- firstly, you have the build the project, in the root directory enter :
```
make
```
- now you have the executable. simply run it with the corresponding commands.
```
./codexion <cdrs> <brn> <tc> <td> <tr> <rqc> <cldwn> <sch>

# cdrs : how many coders in the simulation
# brn : time until a coder burns out
# tc : time it takes to compile
# td : time it takes to debug
# tr : time it takes to refactor
# rqc : how many compilations for each coder
# cldwn : time for dongle to cooldown
# sch : scheduling method ( either fifo or edf)
```
